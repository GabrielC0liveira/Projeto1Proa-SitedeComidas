# 🍽️ Fusion Kitchen

Landing page de um site gastronômico, desenvolvida com **HTML5 e CSS3** como parte de uma atividade prática do curso PROA.

O projeto tem como objetivo explorar conceitos de estruturação de páginas web, estilização de elementos e criação de efeitos visuais interativos utilizando CSS.

## 🖥️ Prévia do projeto

![Prévia do Fusion Kitchen](img/preview.png)

🔗 **[Acesse o projeto online](https://gabrielc0liveira.github.io/Projeto1Proa-SitedeComidas/)**

## Funcionalidades e características

- Layout de apresentação com temática gastronômica.
- Menu de navegação com efeitos de animação ao passar o mouse.
- Botão de chamada para ação (CTA).
- Composição visual com imagens sobrepostas e elementos decorativos.
- Estilização personalizada utilizando CSS.

##  Tecnologias utilizadas

- **HTML5:** estruturação e organização dos elementos da página.
- **CSS3:** estilização, posicionamento, efeitos visuais e animações.
- **Google Fonts:** utilização da fonte Baloo 2.

##  Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação de páginas utilizando HTML semântico.
- Organização de layouts com Flexbox.
- Posicionamento de elementos com CSS.
- Utilização de pseudoelementos e pseudoclasses.
- Criação de animações com `transition` e `hover`.
